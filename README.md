This repository is a structured collection of academic resources for the 3rd semester of B.Tech in Artificial Intelligence and Data Science, Section A. It brings together notes, lab work, and practical files for core subjects in one organized place.

## 📘 Academic Subjects

- 🐍 Python
- 💻 Data Structures and Algorithms (DSA) in C
- 📐 Mathematics for Machine Learning
- 🖥️ Operating System (OS)
- 🗄️ Relational Database Management System (RDBMS)
- 🕉️ Indian Knowledge System (IKS)

## 🗂️ Repository Structure

- Python/
  - Python Lab/
  - Python Theory/
- DSA/
  - DSA Lab/
  - DSA Theory/
- OS/
  - LAB/
  - Theory/
- RDBMS/
  - LAB/
  - Theory/
- IKS/
  - Study notes and supporting material

## 📚 What This Repository Contains

- Theory notes and conceptual summaries
- Lab programs and assignments
- Source code for practical implementation
- Output files and supporting material

## 🚀 How to Use

1. Navigate to the subject folder you need.
2. Review the theory notes for understanding.
3. Open and run the lab programs using the relevant compiler or interpreter.
4. Keep your personal updates and revisions in the same structure.

## 🎯 Purpose

This repository is intended to support academic learning by providing a centralized and well-organized set of study resources for 3rd-sem students.

## 🤝 Contributions

Students and contributors are welcome to add notes, improve existing material, and organize resources for better learning and revision.
