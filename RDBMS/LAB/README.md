# RDBMS Lab Setup

This workspace is ready to run SQL using SQLite.

## Quick start

1. Open the VS Code command palette.
2. Run one of the tasks:
   - SQL: Run lab script
   - SQL: Open SQLite shell
3. The database is stored in `RDBMS/LAB/student.db`.

## Files

- `1.sql` contains the SQL script for your lab work.
- `student.db` is the SQLite database created when the script runs.

## Example

```sql
SELECT * FROM students;
```
