# Dynamic Memory Allocation in C

Dynamic Memory Allocation ka simple matlab hai:
program chalne ke time memory lena, jitni zarurat ho utni lena, aur kaam khatam hone ke baad use chhod dena.

Normal array me size pehle se fix hota hai.  
Lekin DSA me hamesha size pehle se pata nahi hota. Isi liye Dynamic Memory Allocation bahut useful hota hai.

Example:
Agar tumhe class me kitne students aayenge ye pehle se nahi pata, to tum pehle se 100 chairs fix karke nahi rakhna chahoge.  
Jitne students aayen, utni chairs arrange karna zyada practical hai.  
Yehi idea Dynamic Memory Allocation ka hai.

## Real Life Example

Socho tum mall gaye ho:

- `malloc()` matlab ek bada empty room book kar liya, but andar kuch set nahi hai.
- `calloc()` matlab room book kiya aur saari seats starting me properly zero state me hain.
- `realloc()` matlab pehle chhota room liya tha, baad me crowd badh gaya to room ka size bada kar diya.
- `free()` matlab kaam khatam hone ke baad room wapas chhod diya.

## Dynamic Memory Allocation ki Need

- Jab data ka size pehle se pata na ho
- Jab program ko runtime me memory chahiye ho
- Jab memory waste nahi karni ho
- Jab linked list, stack, queue, tree jaise data structures banane ho

## Header File

Dynamic memory allocation functions use karne ke liye:

```c
#include <stdlib.h>
```

## 1. malloc()

`malloc` ka full form hai Memory Allocation.

Ye ek block of memory allocate karta hai.  
Lekin jo memory milti hai usme initial values set nahi hoti.  
Usme garbage values ho sakti hain.

### Real Life Example

Socho tumne ek empty notebook kharidi.  
Notebook mil gayi, but uske pages pehle se filled nahi hain.  
Tumhe khud likhna padega.

### Syntax

```c
ptr = (datatype *)malloc(number_of_bytes);
```

### Example

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n, i;
    int *arr;

    printf("Kitne elements chahiye: ");
    scanf("%d", &n);

    arr = (int *)malloc(n * sizeof(int));

    if (arr == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    printf("Elements enter karo:\n");
    for (i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    printf("Array elements hain:\n");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }

    free(arr);
    return 0;
}
```

### Important Points

- `malloc()` sirf memory reserve karta hai
- Values initialize nahi hoti
- Garbage values mil sakti hain
- Failure par `NULL` return karta hai

## 2. calloc()

`calloc` ka full form hai Contiguous Allocation.

Ye multiple elements ke liye memory allocate karta hai, aur un sabko starting me zero se initialize karta hai.

### Real Life Example

Socho tumne nayi register kharidi aur uske har page par pehle se page number `0` likha hua ho.  
Matlab sab kuch clean aur initialized state me mila.

### Syntax

```c
ptr = (datatype *)calloc(number_of_elements, size_of_each_element);
```

### Example

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n, i;
    int *arr;

    printf("Kitne elements chahiye: ");
    scanf("%d", &n);

    arr = (int *)calloc(n, sizeof(int));

    if (arr == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    printf("calloc ke baad elements hain:\n");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }

    free(arr);
    return 0;
}
```

### Important Points

- `calloc()` multiple elements ke liye memory allocate karta hai
- Sab values starting me zero hoti hain
- Failure par `NULL` return karta hai

## 3. realloc()

Tumne `alloc` likha tha, lekin C me commonly jo function use hota hai wo `realloc()` hai.

`realloc` ka matlab hai re-allocation of memory.  
Ye pehle se allocated memory ka size badhane ya ghataane ke kaam aata hai.

### Real Life Example

Socho tumne 2BHK flat rent par liya tha.  
Baad me family badi ho gayi, to tum 3BHK me shift ho gaye.  
Matlab jagah ka size change ho gaya according to need.

### Syntax

```c
ptr = (datatype *)realloc(ptr, new_size);
```

### Example

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int *arr;

    arr = (int *)malloc(3 * sizeof(int));

    if (arr == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    for (i = 0; i < 3; i++) {
        arr[i] = i + 1;
    }

    arr = (int *)realloc(arr, 5 * sizeof(int));

    if (arr == NULL) {
        printf("Memory reallocation failed.\n");
        return 1;
    }

    arr[3] = 4;
    arr[4] = 5;

    printf("New elements are:\n");
    for (i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }

    free(arr);
    return 0;
}
```

### Important Points

- `realloc()` old memory ka size change karta hai
- Size bada ya chhota dono ho sakta hai
- Kabhi kabhi memory location change bhi ho sakti hai
- Old data usually preserve hota hai, jitna possible ho

## 4. free()

`free()` ka use allocated memory ko release karne ke liye hota hai.

### Real Life Example

Socho tumne hotel room book kiya tha.  
Kaam khatam hone ke baad room vacate karna padta hai.  
Agar vacate nahi karoge, to resource block rahega.

### Syntax

```c
free(ptr);
```

Agar `free()` use nahi karoge, to memory leak ho sakta hai.

## Difference Between malloc() and calloc()

| Feature | malloc() | calloc() |
|---|---|---|
| Full form | Memory Allocation | Contiguous Allocation |
| Arguments | 1 | 2 |
| Initial value | Garbage value | Zero |
| Use | Single memory block | Multiple elements |

## Short 

Dynamic Memory Allocation ek process hai jisme memory runtime par allocate ki jaati hai.  
Ye tab useful hoti hai jab data ka size pehle se fixed na ho.  
C me iske liye `malloc()`, `calloc()`, `realloc()`, aur `free()` functions use hote hain.

- `malloc()` memory allocate karta hai but initialize nahi karta
- `calloc()` memory allocate karta hai aur zero se initialize karta hai
- `realloc()` allocated memory ka size change karta hai
- `free()` memory release karta hai

DSA me ye linked list, queue, stack, tree jaise structures ke liye bahut important hota hai.
